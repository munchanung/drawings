# 찬웅의 그림첩

## 파일 구성
- index.html : 페이지 내용 (그림 제목·설명은 여기서 수정)
- style.css  : 색상·글꼴·모양
- script.js  : 스크롤할 때 그림이 움직이는 부분
- images/    : 그림 사진
- videos/    : 작업 영상

## 들어간 그림
- face-collage.jpg (세로 화면용: face-collage-tall.jpg) : 첫 화면
- blue-base.jpg, blue-face.jpg, blue-white.jpg : 옆으로 흘러가는 그림 줄
- videos/studio.mp4 : 마지막에 커지는 작업 영상
